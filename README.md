# 화성교통안전체험교육센터 모바일 고객만족도 조사 시스템

교육생이 스마트폰으로 QR코드를 스캔해 설문을 제출하면, **하나의 구글 스프레드시트 안에 연도별·교육과정별 시트 탭(예: `26년 개인택시양수`, `26년 버스양성과정`, `26년 일반기본교육(전기차)`)으로 자동 누적·집계**되는 화성센터 전용 모바일 설문 시스템입니다.

---

## 📁 폴더 구성

```text
hwaseong-survey/
├── index.html                    # 통합 메인 (개인택시 양수 / 버스양성과정 / 일반과정 + 상단 🔒 관리자 자물쇠)
├── taxi/index.html               # 개인택시 양수교육 설문 (4단계)
├── bus/index.html                # 버스양성과정 설문 (3단계)
├── general/index.html            # 일반과정 설문 (3단계, 과정 선택 드롭다운 포함)
├── qr.html                       # 비밀번호 보호 관리자 도구 (구글 시트 바로가기 · 연동 확인 · QR 포스터 인쇄)
├── config.js                     # ⭐ 구글 웹 앱 URL / 스프레드시트 URL / 관리자 비밀번호 / 과정 목록
├── assets/
│   ├── survey.css                # 화성센터 전용 딥 틸 · 웜 앰버 모바일 UI 스타일
│   └── survey.js                 # 단계별 위자드, 0~10점 버튼 평가 패드, 중복 방지 전송 로직
└── google-apps-script/
    └── Code.gs                   # 연도·과정별 자동 누적 + 고가독성 리포트 서식 + 통합 대시보드 스크립트
```

## 1단계. 구글 스프레드시트 생성 및 Apps Script 배포 (약 5분)

### ① 새 구글 스프레드시트 만들기
1. 화성센터 전용 구글 계정으로 로그인합니다.
2. 브라우저 주소창에 **[https://sheets.new](https://sheets.new)** 를 입력해 새 스프레드시트를 만듭니다.
3. 왼쪽 상단 제목을 원하는 이름으로 바꿉니다. (예: `화성센터 고객만족도 조사 통합관리`)
4. **지금 브라우저 주소창에 떠 있는 스프레드시트 URL**(`https://docs.google.com/spreadsheets/d/....../edit`)을 복사해 메모장에 잠시 적어둡니다. *(나중에 `config.js`의 `SPREADSHEET_URL`에 넣습니다.)*

### ② Apps Script 코드 붙여넣기
1. 스프레드시트 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
2. 열린 편집기에 있는 기본 코드(`function myFunction() {}`)를 모두 선택해 지웁니다.
3. 이 폴더의 **`google-apps-script/Code.gs`** 파일을 메모장으로 열어 **전체 복사(`Ctrl+A` → `Ctrl+C`)**한 뒤 Apps Script 편집기에 **붙여넣기(`Ctrl+V`)**합니다.
4. 상단 디스켓 아이콘 또는 **`Ctrl + S`**를 눌러 저장합니다. (프로젝트 이름은 `화성센터 만족도조사` 등으로 변경 가능)

### ③ 초기 시트 생성 (`setupSheets` 실행)
1. 편집기 상단 도구모음의 함수 선택 드롭다운에서 **`setupSheets`**를 선택하고 **[실행]**을 클릭합니다.
2. 최초 1회 **권한 검토** 팝업이 나타나면 아래 순서대로 승인합니다:
   - **[권한 검토]** 클릭 → 화성센터 구글 계정 클릭
   - "Google에서 확인하지 않은 앱" 경고 화면에서 왼쪽 아래 **[고급]** 클릭
   - 맨 아래 **[화성센터 만족도조사(안전하지 않음)(으)로 이동]** 클릭 → **[허용]** 클릭
3. 실행 완료 후 스프레드시트 탭으로 돌아가면 **`요약대시보드`**, **`26년 개인택시양수`**, **`26년 버스양성과정`** 시트가 깔끔한 리포트 서식으로 자동 생성된 것을 확인할 수 있습니다.
4. *(선택 확인)* 함수 드롭다운에서 **`testWriteSample`**을 1회 실행하면 택시·버스양성·전기차 샘플 데이터가 1건씩 기록되어 색상 강조·줄바꿈·평균 자동 계산을 바로 확인하실 수 있습니다. (확인 후 4행 테스트 데이터는 삭제하세요.)

### ④ 웹 앱으로 배포해 URL 발급받기
1. Apps Script 화면 우측 상단 파란색 **[배포] → [새 배포]** 클릭
2. 왼쪽 톱니바퀴(유형 선택) 클릭 → **[웹 앱]** 선택
3. 아래 설정을 정확히 확인합니다:
   - **설명**: `화성센터 만족도조사 v1`
   - **다음 사용자 권한으로 실행**: `나 (본인 구글 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자`** *(⚠️ 반드시 '모든 사용자'로 해야 교육생이 로그인 없이 제출 가능합니다!)*
4. **[배포]** 클릭 → 화면에 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/....../exec`)의 **[복사]** 버튼을 누릅니다.

## 2단계. `config.js` 설정 파일 입력 (약 1분)

이 폴더의 **`config.js`** 파일을 메모장으로 열어 아래 3가지를 입력하고 저장합니다:

```js
window.SURVEY_CONFIG = {
  // 1단계-④에서 복사한 Apps Script 웹 앱 URL
  SHEET_URL: 'https://script.google.com/macros/s/여기에_웹앱_URL/exec',

  // 1단계-①에서 복사한 구글 스프레드시트 URL
  SPREADSHEET_URL: 'https://docs.google.com/spreadsheets/d/여기에_시트_URL/edit',

  // 메인 우측 상단 자물쇠(🔒) 클릭 시 입력할 담당자 비밀번호 (원하는 숫자로 변경!)
  ADMIN_PASSWORD: '1234',

  CENTER_NAME: '화성교통안전체험교육센터',
  COURSES: [ ... ]
};
```

## 3단계. GitHub에 올리고 무료 웹사이트 열기 (약 3분)

별도 프로그램(Git) 설치 없이 웹 브라우저만으로 완료할 수 있습니다.

### ① GitHub 새 저장소(Repository) 만들기
1. [https://github.com](https://github.com) 에 로그인(또는 회원가입)합니다.
2. 오른쪽 상단 **`+`** 버튼 → **`New repository`** 클릭
3. 아래와 같이 입력합니다:
   - **Repository name**: `hwaseong-survey`
   - **Public** 선택 *(무료 GitHub Pages 필수)*
4. 맨 아래 초록색 **`Create repository`** 클릭

### ② 파일 및 폴더 업로드하기
1. 저장소 화면 중간의 파란색 **`uploading an existing file`** 링크 클릭
2. 윈도우 탐색기에서 `c:\Users\서동찬\Desktop\회사\화성센터 메뉴얼\hwaseong-survey` 폴더 **안으로 들어갑니다**.
3. 폴더 안의 **모든 파일과 하위 폴더**(`assets`, `bus`, `general`, `google-apps-script`, `taxi`, `config.js`, `index.html`, `qr.html`, `README.md`)를 **`Ctrl + A`**로 전체 선택한 뒤, GitHub 화면의 **`Drag files here`** 영역에 끌어다 놓습니다.
   > ⚠️ **주의**: 바깥쪽 `hwaseong-survey` 폴더 자체를 올리지 말고, 반드시 **폴더 안의 내용물 전체**를 선택해서 끌어다 놓아야 합니다!
4. 파일 목록이 다 올라가면 아래 초록색 **`Commit changes`** 버튼 클릭

### ③ GitHub Pages(무료 웹 호스팅) 켜기
1. 저장소 상단 탭에서 **[Settings]** 클릭 → 왼쪽 메뉴에서 **[Pages]** 클릭
2. **Build and deployment → Branch**에서 `main`과 `/ (root)`를 선택 → **[Save]** 클릭
3. 1~2분 뒤 페이지를 새로고침하면 상단에 배포 주소가 나타납니다:
   - **통합 메인**: `https://<깃허브아이디>.github.io/hwaseong-survey/`
   - **개인택시 양수 전용**: `https://<깃허브아이디>.github.io/hwaseong-survey/taxi/`
   - **버스양성과정 전용**: `https://<깃허브아이디>.github.io/hwaseong-survey/bus/`
   - **일반과정 전용**: `https://<깃허브아이디>.github.io/hwaseong-survey/general/`

## 4단계. 관리자 도구(🔒)로 최종 연동 점검 및 QR 포스터 인쇄

1. 배포된 통합 메인 주소(`https://<깃허브아이디>.github.io/hwaseong-survey/`)에 접속합니다.
2. 화면 **오른쪽 맨 위 자물쇠(🔒) 아이콘**을 클릭하고 `config.js`에 설정한 비밀번호(기본 `1234`)를 입력합니다.
3. 관리자 도구 화면에서 아래 3가지를 차례로 확인합니다:
   - **`🔍 1. 연결 상태 확인 (Ping)`** 클릭 → 연결된 스프레드시트명과 연도·과정별 시트 현황이 초록색으로 표시되는지 확인
   - **`🧪 2. 테스트 데이터 1건 전송`** 클릭 → `26년 버스양성과정` 시트에 저장 성공 메시지 확인
   - 상단의 **`📊 구글 스프레드시트 열기`** 버튼 클릭 → 실제 스프레드시트에서 `26년 버스양성과정` 탭과 `요약대시보드`에 점수가 깔끔하게 들어왔는지 눈으로 확인 후 테스트 행 삭제
4. 하단의 **강의실 QR 코드 생성기**에서 원하는 과정(통합 / 개인택시 / 버스양성과정 / 일반과정 / 특정 과정 자동선택)을 고르고 **[A4 포스터 인쇄]** 또는 **[QR 이미지(PNG) 저장]**을 눌러 강의실에 적용하시면 완료됩니다!

## 💡 운영 팁

- **연도가 바뀌면?**: 아무것도 수정할 필요 없습니다! 2027년 입교일자 설문이 들어오면 `27년 개인택시양수`, `27년 버스양성과정` 시트가 자동으로 새 탭으로 만들어지고 `요약대시보드`에도 자동 추가됩니다.
- **엑셀 파일로 내려받기**: 구글 스프레드시트 상단 **[파일] → [다운로드] → [Microsoft Excel (.xlsx)]**를 누르면 서식과 대시보드 그대로 엑셀 파일로 저장됩니다.
- **비밀번호나 URL 수정**: GitHub 저장소에서 `config.js` 클릭 → 오른쪽 위 **연필 아이콘(Edit)** 클릭 → 수정 후 **`Commit changes`**를 누르면 1분 내에 사이트에 반영됩니다.
- **`Code.gs` 수정 시 주의**: Apps Script에서 코드를 수정한 뒤에는 저장만 하면 안 되고, 우측 상단 **[배포] → [배포 관리] → 연필(수정) → 버전: 새 버전 → [배포]**를 눌러야 기존 URL 그대로 새 코드가 반영됩니다.
